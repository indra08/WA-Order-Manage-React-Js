Alur Penggunaan Sistem

Panduan lengkap cara menggunakan sistem Book Order melalui WhatsApp Group.

1

Admin Posting Buku

Admin 09:00
📚 [Gambar Buku]

BB Pop Up Learning All About Animals - 130k nett✨

Admin 09:01

Stok: 5 | Preview: youtube.com/xxx

Format posting didukung: BB Judul - Harga, BB/Judul - Harga, atau Judul - Harga (tanpa prefix)
2

Customer Reply "Fix" / "Mau"

Sintha 09:15

Fix

Za 09:16

Mau 2 ya

Rina 09:20

Mau

Customer reply dengan kata: Fix, Mau, Mau 2, Pesan, dll. Sistem mendeteksi sebagai Purchase Intent.
3

Sistem Mendeteksi & Admin Konfirmasi

System Auto 09:21

📋 New Reply Detected:

  • Sintha - "Fix" → Pop Up Animals (Rp130k)
  • Za - "Mau 2" → Pop Up Animals (Rp130k x2)
  • Rina - "Mau" → Pop Up Animals (Rp130k)
Admin 09:30

✅ Sintha

Admin 09:31

✅ Za

Admin memberikan ✅ untuk konfirmasi. Reply dengan ✅ akan masuk tagihan.
4

Stok Habis → Reaction ❌ atau X

Dewi 09:22

Fix 1

Admin 09:32

❌ Dewi - Stok habis

Order dengan ❌ atau X TIDAK masuk tagihan.
5

Fix Ulang (Retry Order)

Admin 18:00

📢 Cuma nemu 1, yg tadi di ❌ bisa fix ulang

Dewi 18:05

Fix

Admin 18:06

✅ Dewi

Customer yang sebelumnya ❌ bisa fix ulang jika admin menemukan stok.

Quick Reference - Status Kode

Status Arti Masuk Tagihan?
WAITING_STOCK_CHECK Baru reply, belum dicek stok Belum
✅ CONFIRMED Stok ada, admin konfirmasi Ya
❌ REJECTED Stok habis / ditolak Tidak
WAITING_RETRY Bisa fix ulang Tunggu
INVOICED Sudah masuk rekapan Ya

Keyword Purchase Intent

Kata-kata yang dideteksi sebagai trigger order (purchase intent):

fix fix 1 fix 2 mau mau 1 mau 2 mau 3 mau ya pesan ambil ambil satu ikut yes saya mau aku mau

Catatan: Kata-kata di atas adalah purchase intent, BUKAN otomatis order. Admin harus memberikan ✅ untuk mengkonfirmasi.

Tips & Tricks

📝
Buku & Posting

Gunakan menu Buku & Posting untuk posting buku ke group dan melihat katalog. Buku otomatis masuk katalog saat posting.

��
Multiple Upload

Bisa upload judul buku yang sama beberapa kali dalam 1 hari. Stok akan berkurang setiap ada konfirmasi.

📊
Auto Rekapan

Order dengan ✅ otomatis masuk Google Sheet dengan format: Group, Tanggal, Jam, No. HP, Nama, Kode, Jumlah, Harga, Subtotal.

🔢
Kode Customer

Kode = 4-5 digit terakhir nomor HP. Jika ada duplikasi dengan customer lain, gunakan 5 digit.

📱
Cek Rekapan

Customer bisa cek tagihan via web dengan memasukkan Group Code + Kode.
